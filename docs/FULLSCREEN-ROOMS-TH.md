# ห้องเกมเต็มจอ

เปลี่ยนหน้าห้องนักเรียนและหน้าคุมห้องครูเป็นเต็มจอ ข้อมูลเดิมแบ่งเป็นเมนูแทนการเรียงลงไปตลอดหน้า

| ผู้ใช้ | เมนู | เนื้อหา |
|---|---|---|
| นักเรียน | เล่น | โจทย์ รูป ตัวเลือก/ช่องพิมพ์ เวลา คะแนนข้อ ส่งคำตอบ พลัง เฉลยและคะแนนที่ช่วยทีม |
| นักเรียน | ทีม | ชื่อทีม เปลี่ยนชื่อ/ออกจากทีมตามสิทธิ์ สมาชิก หัวหน้า กติกา พลัง และสถานะคะแนน |
| นักเรียน | อันดับ | อันดับ คะแนนเฉลี่ย รายละเอียดคะแนนรวมและตัวหาร |
| ครู | คุมเกม | โจทย์ เวลา ความคืบหน้า คำสั่งเริ่ม/ล็อก/เฉลย/ถัดไป/จบ |
| ครู | ผู้เล่น | รหัสห้อง รายชื่อและทีม สถานะส่งคำตอบ ผู้มีสิทธิ์คะแนน |
| ครู | คะแนน | คะแนนแต่ละกลุ่มและอันดับ |

เมนูล่างบนมือถือ เมนูบนบนจอใหญ่ กดหรือปัดซ้าย–ขวาได้ ปัดแนวตั้งยังอ่านเนื้อหาได้ การปัดจากช่องพิมพ์ ปุ่มและลิงก์ไม่สลับหน้า Keyboard ใช้ลูกศร/Home/End บนเมนูได้

หน้าหลักไม่มีการเลื่อนทั้งหน้า โจทย์/ตัวเลือกที่ยาวและรายชื่อจำนวนมากเลื่อนภายในกรอบของตนเอง โดยไม่ตัดข้อความ ขยายโจทย์ด้วยปุ่มและขยายรูปได้ ปุ่มส่งอยู่นอกกรอบเลื่อนตัวเลือก

การสลับแท็บรักษาร่างคำตอบ ตัวเลือก และการรับข้อมูลห้อง เมื่อเริ่มข้อใหม่ นักเรียนกลับหน้าเล่น เมื่อจบเกมกลับหน้าอันดับหลังปิดผลการแข่งขัน ครูไม่ถูกเปลี่ยนเมนูอัตโนมัติ

รองรับการย่อพื้นที่จากแป้นพิมพ์ผ่าน VisualViewport โดยซ่อนหัวแอปและเมนูชั่วคราว ไม่ถือการ pinch zoom เป็นการเปิดแป้นพิมพ์ ทั้งนี้การทดสอบแป้นพิมพ์จำลองใน Chromium ไม่แทนการทดสอบแป้นพิมพ์จริงบน iOS/Android

สูตรคะแนน สิทธิ์ครู/นักเรียน และคำสั่งส่งคำตอบใช้ระบบเดิม เพิ่มข้อมูลสมาชิกเฉพาะทีมของนักเรียนใน snapshot สำหรับหน้า “ทีม” ไม่ส่งรายชื่อบัญชีทั้งหมด

การตรวจครอบคลุม production build, lint, data/SQL regression, เกมตั้งแต่เข้าจนจบ, responsive/a11y, โจทย์ยาวและรูป, คำตอบไม่หายหลังปัด, viewport แป้นพิมพ์ และการกลับหน้าเล่นเมื่อเปลี่ยนข้อ หลักฐานอยู่ใน `tmp/room-tabs-audit`, `tmp/ui-audit`, และ `tmp/impeccable-room-tabs.json`

ขอบเขตรอบนี้คือห้องเล่นและห้องครู หน้าจัดการคลังคำถาม สร้างห้อง และรายงานแยกยังใช้หน้าจัดการเดิม

## ผลยืนยัน 11 กันยายน 2026

- Build / TypeScript / lint ผ่าน
- ชุด data regression และ PostgreSQL RPC ผ่าน
- ชุด Playwright หลักผ่าน 14 รายการ อีก 1 รายการตรวจห้องเต็มจอพบสองจุด a11y ในรายชื่อครู หลังแก้สีข้อความและเพิ่ม focus ให้กรอบเลื่อน รันทวนรายการนี้ผ่านแล้ว
- ชุดห้องเต็มจอตรวจ 15 ภาพ/สถานะ รวม 320×568, 390×844, 844×390 และ 1440×900 รวมกับ audit หลัก 32 สถานะ: ไม่พบ document overflow หรือ axe violations ในผลยืนยัน ทั้งยังทดสอบ viewport แป้นพิมพ์จำลองอีกหนึ่งภาพ
- ทดสอบปัดเมนู ร่างคำตอบไม่หาย ตัวเลือกที่เลือกไว้คงอยู่ ขยายโจทย์/Escape ปุ่มส่งอยู่ในจอ และกลับหน้าเล่นเมื่อครูเปลี่ยนข้อ
- Impeccable detector ล่าสุด: 0 primary และ 90 advisory ส่วนใหญ่เป็นสี/ขนาด literal เทียบกับเอกสาร token ไม่ได้ทดสอบ FPS หรือแป้นพิมพ์บนอุปกรณ์โรงเรียนจริง

Local ใช้ข้อมูลทดสอบแยกใน `tmp/local-preview` ที่ http://127.0.0.1:3100/login หน้าตาใหม่ใช้ได้ทั้งห้องเก่าและห้องใหม่ สูตรคะแนนยังขึ้นกับ rulesVersion ของห้องตามเดิม
