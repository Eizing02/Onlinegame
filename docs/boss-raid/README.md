# Boss Raid — Time Attack

เพิ่มโหมดแยกจาก Classic โดยใช้บัญชี Google/RBAC คลังคำถาม และรหัสห้อง 4 หลักเดิม ครูเลือก Classic เป็นค่าเริ่มต้น หรือ Boss Raid หลังเปิด feature flag และติดตั้ง migration 009 แล้ว

## วิธีเล่น

1. ครูเลือกชุดคำถาม จำนวนทีม 1–12 สมาชิก 1–5 คนต่อทีม เวลารวม 1–60 นาที และการเตือนเมื่อออกจากหน้า
2. นักเรียนเข้าสู่ระบบตามเดิม เลือกทีม แล้วเลือกฮีโร่ไม่ซ้ำกันในทีม นักรบ จอมเวท พ่อมด แม่มด หรือภูตพิทักษ์
3. ครูกดเริ่มครั้งเดียว ระบบล็อกผู้เล่น ชุดคำถาม กติกา และ deadline เดียวกันทั้งห้อง ผู้ที่ยังไม่เลือกฮีโร่ได้รับตัวว่างตามลำดับที่แน่นอน
4. นักเรียนแต่ละคนได้คำถามครบชุด ลำดับคำถาม/ตัวเลือกสุ่มแยกและคงเดิมเมื่อโหลดหน้าใหม่ เลือกหรือพิมพ์ → ตรวจคำตอบ → ยืนยัน → ทำข้อต่อไป ไม่รอครูหรือเพื่อน
5. ครูสลับเมนูรับชมทีม / อันดับและผล / รายงานออกจากหน้า รับชมเคลื่อนไหวทีละทีมได้ทั้งเต็มจอและมือถือ
6. หมดเวลาหรือครูจบเกม ปิดการตอบและแสดงผลสองอันดับ พร้อมผลเชิงวิชาการรายคนและ CSV สำหรับครู

คะแนนเฉลี่ยต่อคนและปราบบอสเร็วที่สุดเป็นคนละอันดับ คะแนนหรือเวลาเท่ากันได้อันดับร่วม ผู้ยังไม่ปราบบอสมีความคืบหน้าแต่ไม่มีอันดับ kill ผู้เข้าหลังเริ่มเป็นผู้ชมเท่านั้น

## เส้นทาง

| บทบาท | หน้า / API |
|---|---|
| ครูสร้างห้อง | `/teacher/rooms/new` |
| นักเรียน | `/play/[roomCode]/raid` |
| ครูรับชม | `/teacher/rooms/[roomCode]/raid/dashboard` |
| ครูผล | `/teacher/rooms/[roomCode]/raid/results` |
| นักเรียน API | `/api/raid/[roomCode]/snapshot`, `hero`, `answer`, `visibility` |
| ครู API | `/api/teacher/raid/[roomCode]/overview`, `results`, `control` |
| นักพัฒนาเท่านั้น | `/dev/boss-raid`, `/dev/boss-raid/assets` (404 ใน production build) |

หน้า generic เดิมตรวจ mode แล้วส่งไปหน้า Raid ส่วน API Classic ปฏิเสธคำสั่ง Raid ก่อนทำงาน Google Login และสิทธิ์เจ้าของห้องยังใช้ระบบเดิมทั้งหมด
