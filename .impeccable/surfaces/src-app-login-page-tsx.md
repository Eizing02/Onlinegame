THESIS
Make Google login and account linking readable classroom tasks within the existing KruEIonline shell.
OWN-WORLD
Inherit the established deep navy, violet actions, cyan focus, Thai typography and orbit scene. Operate mode: standard forms and navigation.
STORY
Google verifies the email. The server resolves permissions. Students preview and confirm their own five-digit code; administrators maintain a teacher allowlist.
FIRST VIEWPORT
Login keeps the planet and one Google action. Linking leads with the signed-in email and one code field. Account leads with current identity. Teacher management leads with search, add teacher and named statuses.
FORM
Single-column forms, explicit preview and edit steps, inline errors, accessible labels, loading locks, compact desktop teacher rows that become stacked records on mobile. Retain existing game navigation.
FINISH
Existing tokens and icon library, distinct focus, Thai recovery copy, wrapping names/emails, keyboard-operable controls, pagination and bounded desktop/mobile screenshot audit. No student directory or role picker.
